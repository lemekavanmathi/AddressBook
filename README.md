# Address Book

## 📌 Project Description

The Address Book is a C programming project used to manage contact information efficiently.

It allows users to add, search, edit, delete, list, and save contact details using a CSV file.

## 🚀 Features

- Add a new contact
- Search for contacts
- Edit existing contacts
- Delete contacts
- Display all contacts
- Sort contacts
- Save contacts to a CSV file
- Load saved contacts from a CSV file

## 🛠️ Technologies Used

- C Programming
- File Handling
- Structures
- Functions
- Arrays
- Pointers
- Dynamic Memory Concepts
- CSV File Handling

## 📂 Project Files

- `main.c` – Main program
- `file.c` – File handling operations
- `file.h` – File handling declarations
- `contacts.csv` – Stores contact information

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Compile the C files using a C compiler.
4. Run the generated executable.
